# 隐私与数据边界

> 面向使用者：PTPatronus 是**自托管**工具，所有数据留在你自己的实例里，除非你主动配置了对外通道。本文说明什么加密存、什么会发给第三方、插件能看到什么。

## 一、存在你本地的数据

| 数据 | 存储方式 | 说明 |
|---|---|---|
| PT 站点 Cookie / API Key / 密码 / Passkey | **AES-GCM 加密**后存 SQLite | 密钥自动生成并持久在 `./data/`。删除该目录 = 凭据无法解密 + 全员被踢下线，务必备份 |
| 登录密码 | bcrypt 哈希 | 不存明文 |
| JWT / API Key | 签名令牌 | httpOnly cookie 种在浏览器，JS 读不到 |
| 通知凭据（TG token / SMTP 密码等） | 存 `notify.settings`（SystemConfig） | 部分字段在 API 回显时脱敏 |
| 插件配置 / KV / 日志 | 按插件 ID 隔离存 SQLite | 由插件自身声明和使用 |

## 二、会发往第三方的数据（均需你主动配置）

- **PT 站点**：抓取站点数据时，用你提供的 Cookie/API Key 访问对应站点——这是产品本职。
- **媒体元数据**：TMDB / 豆瓣 / Bangumi / MusicBrainz 搜索时，会发送关键词与配置里的 API Key。
- **通知通道**：Bark / Telegram / 邮件 / Webhook 等 19 个通道，只在触发告警时把你配置的标题/正文发往你填的端点。
- **AI 网关 / AI 助手**：若你配置了 OpenAI 兼容端点，相关文本会发往该端点（可能是自建，也可能是第三方）。
- **字幕翻译插件**（`ptp-ai-subtitle`）：仅当你开启翻译并填了 `openai_base_url` / `openai_api_key`，字幕文本才会发往该端点。
- **在线更新检查**：实例会向官方 update manifest 发起检查请求；可用 `UPDATE_MANIFEST_URL` 改成自建或关闭。
- **站点定义热更新**：从定义的源拉取 YAML 站点定义（不含你的凭据）。

**默认不发任何遥测**：没有匿名使用统计、没有自动崩溃上报。设置 → 关于的「复制诊断信息」只生成文本给你手动粘贴，内容仅含版本号、平台、站点/下载器数量，不含 Cookie / URL / 用户名。

## 三、插件的边界

- 插件是**独立进程**，通过宿主 HTTP API 通信；声明的权限（如 `log:write`、`site:read`）由宿主校验。
- 插件默认不能直接读主数据库；通过受限的 KV 接口按插件 ID 隔离存取。
- 浏览器扩展按白名单向 PT 站点注入 Cookie；只从「设置 → 关于」下载官方扩展包。
- 命令执行类插件（如 `ptp-custom-command`）以 argv 方式执行配置里的命令，**等同主机命令执行权限**——安装前请审阅源码与权限声明。
- 群聊类插件（`group-chat-zone`）的 Cookie 以明文写在插件配置里，并以 Header 发往你填的 post_url；请勿填主力账号 Cookie。

## 四、你应该做的事

1. 备份 `./data/`（含数据库与密钥），不要删或换卷。
2. 公网部署用强密码或 `ADMIN_PASSWORD_FILE`，并在「设置 → OIDC」接 SSO；收敛 CORS / 可信代理。
3. `docker.sock` 与宿主目录挂载默认关闭，开启前评估风险。
4. 给每个第三方通道/插件最小必要权限；定期在插件审计页查看日志。
5. 发现安全问题按 [SECURITY.md](../SECURITY.md) 私密报告。
