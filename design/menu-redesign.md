# PTPatronus 主菜单重构设计稿（定稿 v1）

> 日期：2026-07-13 · 状态：定稿（待进开发） · 范围：Web / Flutter 移动 / Flutter 桌面 三端
> 决策来源：UI 评审拍板 —— AI 仅顶栏、移动端不回归底栏、站点详情用 Tab、云盘合并进文件、消息/公告/娱乐/勋章/后宫/下载器/媒体服务器/插件不移出菜单

---

## 0. 一句话定调

**主菜单只回答"我今天要做什么"，具体功能在它最该出现的上下文里出现。**
从 35 项平铺 → **17 项 / 6 组**，其余 16 项全部配替代触达路径 + ⌘K 兜底，不丢任何功能。

---

## 1. 问题诊断（重构前）

| 维度 | 现状 | 问题 |
|---|---|---|
| 入口总数 | Web 32 + 移动底部 3 = **35** | 远超米勒定律，靠"记位置"而非"扫描" |
| 单组规模 | 基础设施 12、内容获取 8、站点活动 8 | 分组形同虚设，组内仍长列表 |
| 层级 | 全一级，无折叠/子菜单 | Web `.nav` 已 `overflow-y:auto` 标准视口即溢出 |
| 快速访问层 | ❌ 无命令面板/收藏/最近 | 新手唯一路径＝扫读 35 项 |
| 顶栏 | 只有 `☰+通知+用户`，中间空白 | 黄金跳转位闲置 |
| 移动端 | 35 项全进抽屉 | 一屏 5–6 项，滚 6 屏到底 |

---

## 2. 设计原则

1. **任务驱动**——按"用户要完成的事"组织，不按"系统有什么模块"。
2. **上下文触达优先**——per-site 功能进站点详情；配置类进设置。
3. **做减法但不丢失**——移出菜单的每项必有可发现替代路径；⌘K 全量兜底。
4. **三层访问梯度**——高频常驻 → 中频上下文 → 低频可搜。
5. **渐进披露**——组可折叠，详情可下钻。

## 5. 替代触达路径设计

移出菜单的 16 项靠这四条路径消化（通知中心不再吞消息/公告，更多页取消）。

### 5.1 站点详情聚合页（消化 B 类 6 项，Tab 形态）

点任意站点 → 顶部 Tab 承载所有 per-site 活动：

```
┌──────────────────────────────────────────────────────┐
│ ◀ 站点 [好大]  ●在线  等级 User  上传 1.2T           │
├──────────────────────────────────────────────────────┤
│ 概览 │ 考核·契约 │ 刷流 │ 辅种 │ 站免 │ 监护         │   ← 后宫不在此（留菜单）
├──────────────────────────────────────────────────────┤
│  考核·契约                                            │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐                │
│  │ 保级进度 │ │ 分享率   │ │ 上传差额 │                │
│  │  78%     │ │  2.31    │ │  +120G   │                │
│  └─────────┘ └─────────┘ └─────────┘                │
│  告警阈值（契约）：[编辑]                             │
└──────────────────────────────────────────────────────┘
```

吸收：考核、保种契约、刷流、辅种、站免、监护室 → **6 项出菜单**。

### 5.2 文件页升级为统一存储浏览器（消化 云盘）

文件页左侧/顶部切换存储后端，STRM 作为选中动作：

```
┌──────────────────────────────────────────────────────┐
│ 文件   [本地] [NAS] [115] [夸克] [123]   🔗连通性 ▾   │
├──────────────────────────────────────────────────────┤
│  路径 /Movies/2025                                   │
│  ☐ movieA.mkv   4.2G   [生成 STRM] [整理]            │
│  ☐ movieB.mkv   3.8G   [生成 STRM] [整理]            │
│  …                                                   │
│  已选 2  → [批量生成 STRM] [批量整理]                 │
└──────────────────────────────────────────────────────┘
```

复用既有 `StorageBackend` 抽象，云盘作新后端类型；云盘"订阅追更"并到订阅页。**云盘 1 项出菜单**。

### 5.3 系统设置收纳器（消化 C 类 10 项）

```
系统设置
├─ 连接      Trakt · 云盘账号（下载器/媒体服务器留菜单，不重复）
├─ 媒体      媒体质量 · 字幕源 · 整理规则 · 过滤规则
├─ 自动化    刷流默认策略 · 定时任务（工作流/插件留菜单）
├─ 通知      通知设置 · 通道(TG/微信/QQ) · 告警规则
├─ 维护      备份 · 诊断 · 运行日志 · 安全模式
└─ 通用      主题 · 语言 · AI 网关 · 目录监视
```

吸收：Trakt、媒体质量、字幕、过滤规则、整理规则、通知设置、备份、诊断、运行日志 → **10 项出菜单**。RSS 进订阅页 Tab 另计。

### 5.4 仪表盘任务卡片 + 命令面板 ⌘K

- **仪表盘卡片**：保级风险 / 待整理 / 刷流中 / 站点健康 / 辅种建议 / 健康自检，点卡片直达对应功能。被动消费 → 主动推送入口。
- **⌘K 命令面板**：全部 35 项 + AI 指令 + 最近访问，fuzzy 匹配（含 PT 黑话：刷流/保级/H&R），老用户零学习成本。

## 7. 命令面板 ⌘K 交互

- **唤起**：`Ctrl/⌘+K`（Web）、顶栏搜索框点击（三端）。
- **匹配**：fuzzy 命中 35 项 label + 别名（刷流/保级/H&R）+ 描述。
- **分组**：最近访问 / 跳转 / 动作 / AI 提问。空输入显「最近 5 + 收藏」。
- **键位**：↑↓ 选、⏎ 跳、`⌘+⏎` 新标签、Esc 关。
- **动作项**：一键整理 / 全站刷流 / 切主题 等直达。
- **AI 模式**：`?` 或 `问 ` 开头转 AI 助手。

## 8. 收藏与最近访问（数据模型）

```ts
// localStorage，key: ptp.nav
{
  favorites: ['dashboard', 'subscriptions', 'workflow'],  // ≤6
  recents: [{ name: 'assessment', at: 1719900000 }, ...], // LRU ≤8
  collapsedGroups: ['tools'],
}
```
- 新用户默认收藏：仪表盘 / 搜索 / 订阅。
- 收藏区固定侧栏顶部、移动端抽屉顶部，跨组。

## 9. 视觉与动效规范

- **组折叠**：高度过渡 250ms ease，chevron 90° 旋转；记忆折叠态。
- **选中态**：保持现有 `linear-gradient(135deg, 紫→蓝, .18)` 玻璃高亮。
- **命令面板**：居中浮层，距顶 15vh，宽 min(640px,90vw)，`blur(18px)`，与 `NavPanel` 同体系。
- **顶栏搜索框**：占位 `🔍 跳转到… (⌘K)`，聚焦展开命令面板。
- **彩色 GlassIcon**：全部保留，品牌识别不退色。
