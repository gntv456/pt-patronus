# ptp-dirwatch

本地目录监视 → 整理流水线。**独立实现，替代宿主进程内 dirwatch**（issue #34 二梯队打样；原宿主模块已随本插件删除）。

## 语义

- **轮询监视**：cron 周期扫描监视目录（默认每 5 分钟），媒体扩展名命中的新文件喂给宿主 `transfer_discovered`
- **写稳定性**：喂之前 size 两次采样一致（≈2s）才视为写完，避免投喂半截文件
- **去重双层**：插件侧 per-dir 已见锚点（KV）+ 宿主整理侧硬链级去重（锚点丢失不致重复入库）
- **失败重试**：投喂失败不更新锚点，下轮自动重试

## 配置

| 键 | 说明 | 默认 |
|---|---|---|
| `dirs` | 监视目录，每行 `路径[|库路径]` | 空 |
| `media_exts` | 媒体扩展名（逗号分隔） | .mkv,.mp4,… |
| `cron` | 扫描定时 | `*/5 * * * *` |
| `notify` | 命中后通知 | 关 |

## 迁移说明

老配置（SystemConfig `dirwatch.config`）不自动迁移：把原「监视目录」逐行填进插件设置即可（格式 `路径|库路径`）。前端「整理」页的目录监视入口由本插件的设置面板承接。

## 能力来源（宿主 Tool RPC）

| 工具 | 权限 |
|---|---|
| `transfer_discovered`（本插件打样新增） | `transfer:write` |
| 通知 / KV / 日志 | `notice:write` / `kv:read,write` / `log:write` |
