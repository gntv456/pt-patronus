# ptp-mcp-server

MCP 配置面板与工具清单查看。注意：MCP HTTP 端点由宿主内置提供（无需安装本插件即可使用 MCP），本插件仅承接配置可视化与可观测动作。

Former PTPatronus built-in, now open-source market plugin. The MCP HTTP
endpoint itself stays in the host (`ptp-mcp-server` host builtin anchored by
`MCPPluginID`); installing this market entry is optional and only adds a
config panel + observability actions.
